# Status badge

`<x-status.badge>` exibe um status semântico com ponto colorido e fundo suave, seguindo o padrão usado nas tabelas do protótipo.

```blade
<x-status.badge label="Success" variant="success" />
<x-status.badge label="Declined" variant="danger" />
<x-status.badge label="Processing" variant="neutral" />
```

Variantes: `success`, `warning`, `danger`, `info` e `neutral`.
